# Sales & Customer Analytics Dashboard

## Overview
End-to-end analytics project using SQL, Power BI, Tableau, and Excel on the Superstore dataset.

## KPIs
- Revenue
- Profit
- Profit Margin
- Orders
- Average Order Value (AOV)

## Analysis
- Top Customers
- Category Performance
- Monthly Revenue Trends
- Regional Performance
- Top States by Revenue

## Tech Stack
SQL, Power BI, Tableau, Excel, GitHub
